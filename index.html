    다운로드한 이미지를 바탕화면으로 설정하는 방법

    Windows 10 · 11 — 저장한 PNG 파일을 마우스 오른쪽 클릭 → 바탕 화면 배경으로 설정. 또는 설정 → 개인 설정 → 배경 → 사진 찾아보기에서 선택하고, 맞춤 방법을 채우기 또는 맞춤으로 지정하세요.

    macOS — Finder에서 파일을 오른쪽 클릭(또는 Control-클릭) → 데스크탑 사진으로 설정. 또는 시스템 설정 → 배경화면 → 사진 추가.

    모바일 — 세로 해상도 프리셋으로 저장한 뒤 사진 앱에서 배경화면으로 지정하세요.

    글자가 흐릿하면 모니터 해상도와 같은 크기로 다시 저장해 보세요.

    모든 처리는 브라우저 안에서만 이루어집니다. 입력한 내용은 서버로 전송되지 않습니다.
